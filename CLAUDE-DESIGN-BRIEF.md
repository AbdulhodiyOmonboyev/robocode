Menga **Robocode IT Academy** uchun bitta sahifali (one-page) landing sayt dizaynini yasab ber. Desktop va mobil versiya. Til — **o'zbek**.

## BREND VA USLUB

- **Fon:** to'q qora–binafsha gradient (`#08060F` → `#1E0B3C` → `#2A0E5A`). Qorong'i, "premium tech" hissi.
- **Asosiy urg'u rang — BINAFSHA:** `#7C3AED` va `#A657F2` (yorqinroq variant), asosiy brend `#5E2CA5`.
  Urg'u binafshada bo'lsin: sarlavhalardagi kalit so'zlar, tugmalar, ikonkalar, badge'lar, chegaralar, nurlar — **hammasi binafsha ohangda**.
- **Ikkilamchi:** oq matn, kulrang `#A1A1AA`. Yashil rang **ishlatilmasin**.
- **Shrift:** Inter / grotesk. Sarlavhalar — juda katta, **BOLD, KATTA HARFLI**. Matn — toza, o'qilarli.
- **Logo:** oq robot ikonka + "robocode" yozuvi (yumaloq boshli robot, ikkita antenna, ikkita vertikal ko'z), binafsha fonli yumaloq kvadratda.
- **Kartalar:** `rounded-2xl`, to'q shaffof fon, yengil **binafsha** chegara/nur, hover'da binafsha porlash.
- **Kayfiyat:** yosh, energiyali, texnologik, ishonchli. Stripe / Linear darajasidagi zamonaviylik, binafsha gamma.
